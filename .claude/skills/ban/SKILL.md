# 盤（ban）

この OS は層が多い。ホストの道具とビルド、媒体、起動、カーネル（arch・mm・sys・fs・net・dev・gui）、ネイティブ ABI、libc、移植（llvm・mesa・quickjs・lexbor・ffmpeg・go・rust）、ブラウザー（取得・解析・DOM・CSS・配置・描画・JS・Worker・媒体）、窓、NVIDIA（RM・Mesa）、VM（QEMU・Hyper-V）。ブラウザーの症状の原因が mesa・llvm・カーネル・格納庫・ABI にあることがある。

長い作業で起きることは二つ。一つは、今どの層のどの候補を調べているか、何が済んで何が残るかが目の前から消えること。もう一つは、一つの候補に心が縮んで、隣の層も、目的も、持ち主の意図も見えなくなること。縮むこと自体は悪くない。深く見るには縮む。悪いのは、縮んでいると知らないまま縮んでいること。盤は、対象と自分を同じ一枚の上に置いて、知る場所。記録ではなく、今の判断。

## 盤の形

`.claude/ban/<鍵>.md`。鍵は会話の識別子で、会話の始まりにフックが道を知らせる。3000 字まで。Write で丸ごと書く（追記しない。番号を付けない。Edit で一行足さない）。

```
# 目的と受入
一行。何が見えたら終わりか（fps、実時間、画面、通る試験）。自分の理解で書く。

# 範囲と禁止
触る層とファイル。触らない所。

# 候補（層ごと）
| 層 | 主張 | 何を見たら消える／決まる | 状態と証拠 |
生きている候補だけ。消えた候補は一行「消えた：層、理由」で五つまで。

# 済んだ手（五行まで）
手と、それで盤のどこが変わったか。変わらなかった手は、要らなかった手。

# 残りの手（順に）
一番上が次の一手。候補を一つ消すか決める手。

# 未確認
言い切っていない前提。途中で見つけた別の不具合もここに一行。
```

盤に書くのは対象の判断だけ。自分の状態は書かない（書けば記録になる）。知るのは手を打つ瞬間。

## 手を打つ前に、自分を知る

盤を見るたび、手を打つ前に、一度だけ問う。直すためではなく、知るため。知った時点で手が変わる。

**心の形。**縮んでいるか、散っているか、どちらでもないか。

- 縮んでいる：候補が一つの層にしかない。同じファイルを何度も開いている。上（目的）も横（隣の層）も見ていない。知ったら、隣の層（上流と下流）の候補を一つずつ盤に足して問う。縮みは解かなくてよい。横に一つ置くだけ。
- 散っている：開いたものは多いが、一番上の候補が無い。手が候補を消すためでなく、何か動いていたいために出ている。知ったら、一番上の候補を一つ決めて、それを消すか決める手だけを打つ。
- どちらでもない：そのまま進む。

**蓋。**有るか無いかを知る。有ると認めるだけで、戦わない。有ると知ったときの手は一つ。

| 蓋 | この作業での形 | 有ると知ったときの手 |
|---|---|---|
| 欲 | この直しが答えであってほしい。終わらせたい。証拠を確かめるためでなく、合うように読んでいる | 候補を消す証拠を先に探す |
| 怒り | 正されたことに抗っている。コード・道具・相手を責めている | 証拠を見直し、合っていればそのまま進み、違っていれば盤を直す。言い返さない |
| 眠り | 要約の次の一手、前の盤、最初に当たった一行、参照の実装を、見ずに取っている | 今のコードとログで照らす |
| 浮つきと悔い | 止められた後に急いで繕っている。謝っている。小さな編集を続けている。多くのファイルを一度に開いている | 手を止めて盤を書き直す。繕いの編集は始めない |
| 疑い | どの観察にも乗らない。ぼかしている。見ずに聞いている | 一つの観察を一行で言い切り、それを確かめる手を打つ |

**内と外と両方。**内は今の候補とファイル。外は隣の層、目的、持ち主の意図。両方は、その二つが同じ方向を向いているか。盤を見る順はこの順。内だけを見続けているなら、縮んでいる。

**掴まない。**候補は観察で、持ち物ではない。消えるのは普通で、良いこと。直しも同じで、効かなかった直しは戻す。持ち主の言葉も同じで、言葉を掴まず、意図を知る。知る分だけ知って、何にも寄らない。

## 盤を作業の一部にする

- 最初の編集の前に書く。前の会話の続きなら、`.claude/ban/` の新しい盤を開き、中の事実を今のリポジトリと照らしてから書く。
- 手の結果が出るたび（ログを読んだ、直した、測った、監査が返った）、その手が盤のどこを変えたかを書き換える。候補の状態、消えた候補、残りの手の順。起こることと消えることを見る。
- 一つの手を、一つの手として打つ。ビルド、ログを読む、編集する、測る、報告する、待つ。今どれをしているかを知って打つ。五つを一度に出すのは、動いていたいだけのことが多い。
- 済んだ作業の目録、事実の写し、設計の本文は盤に入れない。起きたことは git と記録に、設計の本文と監査の全文は `docs/` にあり、盤にはその道だけ。盤が長くなるのは、判断の代わりに目録を書き始めた合図。
- 台帳（LEDGER）には書かない。終わりに一度、盤の最終の形を `docs/` の日付入りの報告へ写す。
- 区切りの報告は盤そのもの（上の形）。別の文を作らない。

## 一歩引く印

次のどれかが出たら、それは上の「自分を知る」を飛ばした印。手を止めて、一度問い、盤を書き直す。

- 直しが症状を変えなかった（欲か眠り）。
- 同じ手を二度打とうとしている（縮み）。
- 証拠（ログの行、コードの原文）が別の層を指している（縮み）。
- 観察が一番上の候補と矛盾した（欲）。
- 候補が一つの層にしかない（縮み）。
- ユーザーに止められた、進め方を正された（外を見ていなかった）。

止められたときは、新しいビルド・編集・計測を始めない。自分が起動したものを確かめて要らないものを止める。自分の流れ（`git status`、`git diff --stat`、盤の済んだ手）を一つの命令で見て、外（目的、持ち主の意図）と内（自分の手）が同じ方向を向いているかを問う。逸れたなら、どこで、なぜ。目的の理解そのものが違っていたなら、何を取り違えたか。盤を書き直し、盤の形で報告して、次の指示を待つ（進め方の選び直しはユーザーの判断。AGENTS.md「止まる理由」の一つ目）。直す指示が付いていればそれが先で、報告は短く。ユーザーの言葉を引用・要約・数えない。見るのは自分が何をしていたか。

## 層を決める観察

症状をどの層へ置くかは、観察で決める。推測で置かない。

- ブラウザーの行（`[browser log/trace @秒]`、F12 の Console・Trace）：取得は `Net #`、媒体は `Native media timing`、描画と待ちは `Browser loop/damage profile`、JS は `JavaScript profile`・`caught exception`・`promise rejected`。行の一覧は `nocturne-project` の `references/logs.md`。
- カーネルの行（時刻なし）：`prof:`（CPU・task・標本・切り替え・TLB）、`[memory]`、`store:`、`video:`。止まって見えたら HMP の `info registers -a` と `build/kernel.elf` の llvm-symbolizer。
- 移植の層（mesa・llvm・quickjs・lexbor・ffmpeg）：上流の同じ版（`D:\Programes\cloned repos`）と我々の接着の差。誤りは接着・渡す値にある見込みが高い。
- ABI・libc：`common/abi.h`・`docs/nocturne-native-abi.md` の契約と、呼ぶ側の実際の値。
- VM だけか：QEMU と Hyper-V で同じか、`kernel/src/vm/` の入口を通るか。
- 層の境界と持ち主の一覧は `.claude/rules/map.md`「境界」。

## 再開と圧縮の後

フックが盤を見せる。要約の「次の一手」へ直行せず（眠り）、盤の残りの手の一番上と見比べる。違えば、なぜ違うかを一行書いて盤を直してから進む。

## サブエージェント

監査に出すときは、盤とコードの場所だけを渡し、自分の結論は渡さない（結論を渡すと、確かめられて返ってくるだけになる）。帰ってきた報告は `docs/` へ全文。盤には候補の変化だけを書く。

## フックが止めるもの

フック（`.claude/hooks/ban.py`）の拒否文はこの一覧を指す。止めるのは、取り返しの付かない費用（RAM・ディスク・何時間もの待ち）を生む命令だけ。止められたら迂回せず、やり方を変える（手順は `nocturne-project`、理由は AGENTS.md「確かめ方」「ビルドと媒体」）。

- QEMU を窓なし（`-display none`・`-nographic`）で起こす命令。
- 三台目の QEMU になる命令。手で起こすものも、`wpt.py`・`test.py` が起こすものも。
- `nocturne.img` の写しで三つ目の媒体になる命令（cp・copy・Copy-Item・robocopy・`qemu-img convert`、道具の写しも）。
- `scripts/wpt.py`・`test.py` を、窓なしの印（`-display none`・`CREATE_NO_WINDOW`）がスクリプトに残る間に走らせる命令。`platform_qa.py`・`qtest.py` は常に。
- `build/qa`・`build/nocturne-platform` に触れる命令（読むだけのものは除く）。
- 目標の無い `scripts/build.py`。
