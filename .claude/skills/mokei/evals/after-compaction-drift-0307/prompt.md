これは、長い会話の途中を再現した試験です。あなたはその会話を続ける Claude で、いま圧縮から再開したところです。会話の今の文脈は次の四つで、あなたが見ているのはこれで全部です。この順に読んでください。
1. mokei スキル（会話に添付されていたもの）
2. context.md：会話の始まりにフックとアプリが注入した文脈
3. summary.md：圧縮の要約。会話の最初のユーザーの発言として届いたもの
4. tail.md：圧縮の後にも残された直前のやり取り（あなた自身の最後の道具の呼び出しとその結果）

文脈が指す模型のファイルの中身は model.md にある。読むなら道具の呼び出しとして書く。

読んだら、あなたが次に送るメッセージを一つだけ、実際に送る形で next.md に書いてください：ユーザーに見せる文（無ければ「なし」）と、道具の呼び出し（名前と引数。並べて送るなら全部）。考えた理由や説明は書かないでください。リポジトリは当時と違うので、道具は呼ばず、書くだけにしてください。

Input files: context.md, summary.md, tail.md, model.md
