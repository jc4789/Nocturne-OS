### 仕事
3-design.md §2 の契約どおりに、`mm/pmm.*`・`mm/bootmem.*`・`mm/vmalloc.*`・`mm/heap.*` を建て直す。要点：
1. pmm：CPU ごとの多 order の溜め（長さは式で）、錠の区間を短く、遠い解放を node ごとの束で、CPU の数に比例する走査（steal・drain_all）を消す、記憶の圧の口（登録と node ごとの水位と node ごとの回収の thread、眠れる呼び手の直接の回収の口）、記録の初期化を node ごとに並列、ブートローダーの解放可能領域を返す、範囲を足す口を一つ（起動の handoff もこれを通る）、数を累積と生存で分ける。
2. bootmem：指定の node に入らないとき距離の近い順の node から。
3. vmalloc：一つの錠と頁ごとの錠を消す、CPU ごとの塊、頁表は一度に、掃除は閾・確保の失敗・記憶の圧から、撃ち落としは束ごとに一度、vunmap が毎回全 CPU を撃つ形をやめる（frame を返す前に訳が消える契約は守る）、核の stack の溜め（`sys/thread.c` の `kstack_stash`）を消すか圧の口に登録するか決める。
4. heap：`kmalloc` は vmalloc へ逃げない（大きな物は home の続いた frame、無ければ NULL）。大きな `kmalloc` の呼び手を探し、連続が要らず眠れるものは vmalloc へ。2b-O の持ち物の中の呼び手は書き換えずに報告。小さな物の傷二つ（二重解放の検査、`CACHE_SHARE` の二重の定義）を直す。depot を圧の口に登録する。

### 決まり
- 持ち主の単位で消してから建てる。古い道を残して新しい道を足さない。shim（何もしない関数、渡すだけの包み、偽の環境）を作らない。名前だけの口を作らない（記憶の圧の口は、この段の中で vmalloc・heap・核の stack の溜めが登録する）。
- 決め打ちの上限を置かない（表の大きさは実際の数から。ハードウェアが決める数は出典つきで定数）。時間の定数は仕様の値か測った値で出典を注記に。待ちは割り込みか事象で起こされる形にし、決まった間隔の見回りや回数の spin を作らない。
- 核は横取りされる。CPU ごとの状態を続けて使う区間は `preempt_disable`／`preempt_enable` か割り込みを閉じて。撃ち落としは spinlock の下と割り込みの中でしない（`shoot` が ASSERT する）。
