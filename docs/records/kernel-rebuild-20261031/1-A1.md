## 2. 建てたもの（口・契約・上限の出所）

**preempt.h（新）**
- `PERCPU preempt_count` の bit の分け方：
  - 0〜15：`preempt_disable` と、持っている spinlock の数。
  - 16〜23：割り込みの処理の深さ。
  - 24〜27：NMI と #MC の深さ。
- 口：`preempt_disable/enable`・`in_interrupt`・`in_nmi`・`preemptible`。

**spin.h（MCS の錠）**
- `struct spinlock {tail, holder, rank}`。口の名と意味は今のまま（`spin_lock/unlock/take/give/held/seize`）。
- CPU ごとの node は `SPIN_NODES`=4。出所は設計の「余裕を持たせて 4」（待ち、NMI、#MC、予備）。
- rank：
  - CPU ごとの bit の列で持ち、持っている最上位の rank 以下を取ると `spin_fault`（panic）。NMI の中では検査しません。
  - `enum spin_rank` は空です。A1 の持つコードは自分の spinlock を持たず、待ちは sched の wait queue を使うためです。
- 足した口 `spin_none_here()`：自分の CPU が錠を持たず待ってもいないかを答えます。NMI と #MC が記録を書いてよいかの判定に使います。

**cpu.c**
- `bool cpu_setup(unsigned index)` を、起動の CPU 0・AP・S3 の後で同じ順に通します：
  1. `gdt_init_cpu`（GS の基も）
  2. CR0（WP・NE・MP を立て、EM・TS・CD・NW を落とす）
  3. CR4（PGE・FSGSBASE・SMEP・SMAP・OSFXSR・OSXMMEXCPT・OSXSAVE、あれば UMIP）
  4. EFER（NXE・SCE）
  5. x2APIC へ入る
  6. `entry_load`
  7. 投機の対策（AutoIBRS は EFER.AIBRSE。無ければ「常時」を好む CPU だけ IBRS、STIBP も同じ）
  8. PAT と MTRR
  9. XCR0 と XSS
  10. MCA
  11. CPPC
- mm 向けに `cpu_ibpb()` を出しました。
- MCA：
  - bank の数は MCG_CAP から読みます。決め打ちせず、上限は番地の幅で、従来型 32・SMCA 64（APM 9）。
  - SMCA は McaxEn を立て、CTL を全部開き、起動時の STATUS を記録してから消し、MCG_CTL を開き、CR4.MCE は最後。
  - `cpu_machine_check(regs)`：RIPV が無いか UC・PCC なら panic。それ以外は消して続けます。
  - `cpu_mca_interrupt_on()`：AMD の threshold を x2APIC の拡張 LVT へつなぎます（誤り 1 回で割り込み）。APIC が有効になった後に呼びます。ソフトで無効の APIC は LVT をすべて mask のまま保つためです（APM 16.4.7）。
- LFENCE：CPUID 8000_0021 EAX[2] で判定し、立っていなければ起動の行に書きます。

**pat.c**
- `pat_cpu_setup()`：MTRR は CPU 0 が最初に見た値を基準にし、違うときだけ SDM 14.11.8 の手順で揃えます。PAT も違うときだけ書きます。

**fpu.c**
- `fpu_init()` は配置だけを決めます。
- `fpu_cpu_setup()` は XCR0 と XSS=0 を書いて確かめます。

**wake.\***
- trampoline は一つです。
- 全 CPU が `tramp_lm64` で x2APIC へ入り（APM 16.9.1 と 16.10）、`struct wake_cpu` の行を x2APIC ID で探します。
- 口：`wake_prepare_any`（S3 の BSP）、`wake_prepare_cpus`（AP の表）、`wake_long_entry`（休止の復元が使う）。
- `wake_sleep` は起きた後に `cpu_setup(0)` を通ります。

**smp.c**
- `smp_init(void)` は全 AP を一斉に起こします。順番：
  1. 全員に INIT
  2. `LAPIC_INIT_WAIT_NS`（10 ms）待つ
  3. STARTUP を 2 回。それぞれの後に `LAPIC_STARTUP_WAIT_NS`（200 µs）待つ。出所は SDM 11.4.4.1 と表 11-1、定数は apic.h のもの。
- 答えは二段で、締め切りは一つです：
  - 「present」：LAPIC まで立った。
  - 「settled」：割り込みの stack が取れた、または取れなかった。
  - 締め切り `START_ANSWER_NS`＝100 ms（SDM 11.4.4.1 の step 14）は最初の答えにだけかけ、来なかった CPU は外します。
- 待ちはどれも、数える語の上で `wq_wait_unless` で眠ります（見回りなし）。
- その後 TSC を比べ、各 CPU が自分で online の集合に入ります。
- `smp_suspend`：全 CPU を一斉に止め、締め切りは一つ（`PARK_WAIT_NS`）。止まった CPU が待ち行列を起こします。
- `smp_resume`：起動と同じ道を通り、その前に CPU 0 の `cpu_mca_interrupt_on` を呼びます。
- `smp_hold_in_init`：INIT の後に `sleep_until` で待ちます。
- `cpu_kick`：先に `cpu_idle_wake` を試し、だめなら IPI。
- 新しい口 `smp_nmi(regs)`：他の CPU の panic なら止まり、それ以外は数えて記録し、戻ります。
- `smp_get_info`：実の値を返します（detected＝`topology.cpus`、online、scheduler＝online、flags＝SSE2|AVX|USER_THREADS、worker 系は 0）。
- CPU ごとの写しは各 CPU の home node に置きます。

**idle.c・idle.h（新）**
- `cpu_idle()`：MWAIT があれば、自分の行に一つだけある語を MONITOR して C1（hint 0）で待ちます。無ければ `sti; hlt; cli`。
- `cpu_idle_wake(cpu)`：その語に書いて起こします。
- CPPC：
  - EPP の既定は一か所の名前つきの値 `CPU_PERF_PREFERENCE_DEFAULT`（0x40）。
  - 範囲は lowest nonlinear から highest、desired は 0。
  - `cpu_perf_set_policy(epp)` は、各 CPU に縛った thread が自分の CPU へ書きます。
- APERF/MPERF の 1 秒の窓：`cpu_perf_sampling/sample/of`。

**その他**
- dev/hibernate.c：最後の写しの小片（`hib_copy_start`）と `restore_jump` を受け取り、像の `VERSION` を 2 から 3 に上げました。
- boot.c の順：
  1. 機能の検出 → `fpu_init` → `idt_init` → `cpu_setup(0)`
  2. bootmem・ACPI・topology・percpu・pmm・heap・vmm・vmalloc・入口の stack・`log_init`・wake
  3. fb → `vm_detect`
  4. pic・ioapic・`apic_init(NULL)`・`cpu_mca_interrupt_on`
  5. clock → sched
  6. `kmain_scheduled` の中で `alarm_init_cpu`・`log_start`・`prof_init`・`smp_init`
- cmdline の読みは boot.c へ（`kernel_cmdline` の持ち主）、端末の鍵の訳は sys/stream.c の `console_key` へ移しました。

## 3. 契約から外れた所と理由
- **DE_CFG（C001_1029）の bit 1 は書いていません。** 手元の資料にありません。CPUID の印で判定し、無ければ起動の行に書きます。
- **起動の順の二点：**
  - heap と vmalloc は割り込みより前のままです。`vmalloc_init` が kzalloc を使い、入口の stack と MMIO の写像が vmalloc を使うためです。
  - `vm_detect` は clock_init の前のままです。今の clock.c（B）とアプリの時計の頁が Hyper-V の参照時刻を読むため、後へ回すと QEMU+WHPX でカーネルとアプリの時計が分かれます。B の TSC だけの時計が入れば、`kmain_late` へ一行で移せます。
- **x2APIC だけにしたことに伴う危険：** `apic_init(NULL)` でも、A2 の apic.c の `x2apic_leave` は IOMMU の衝突があると xAPIC へ戻ります。そのとき `cpu_mca_interrupt_on` が x2APIC の MSR（0x803・0x840・0x850）を読んで #GP になります。A2 で `x2apic_leave` を消すまで、IOMMU のある実機では危険です。QEMU の既定（IOMMU なし）では当たりません。
- x2APIC へ入るのは IOMMU より前です（SDM 13.12.7 の順から外れる）。これは前と同じ外れで、前は Limine が同じことをしていました。
- 深い C 状態は作っていません。`_CST` を評価しておらず、B の ARAT の口もまだ無いためです。
- 手元で確かめていないもの：
  - CPPC の MSR の配置は、手元の PPR に載っていません。
  - SRSO と SSBD は未確認で、何も立てていません。
  - Intel HWP は作っていません（CPPC だけ）。
- **出所の無い値：** `PANIC_STOP_WAIT_NS`（100 ms）と `PARK_WAIT_NS`（2000 ms）は前の値をそのまま持ってきました。
- **spin.h に `void vmm_tlb_poll(void);` の宣言を一行残しました。** sys/alarm.c（B）が mm/vmm.h を含まずに呼んでいるため、消すと組めません。alarm.c が自分で含めば消せます。
- **建てたが、まだつないでいない口：** `smp_nmi` と `cpu_machine_check`。idt.c は A2 の持ち物なので、つなぐのは A2 です。
- wm.c の wmbench は、順に描く形で残しました。合成は常に直接描きます。
- **main を私の枝へ取り込みました。** 本体の知らせのとおり、`log_init` と `log_start` を指示の位置に置きました。
- 古くなったが直していない注記：
  - kernel.h の cmdline の注記がまだ「(init.c)」と書いています（kernel.h は私の持ち物ではないので触っていません）。
  - 休止の像は、組みが同じことを確かめていません（前からの制約）。
