- 読んだのは今のソースだけです。
- 動かして確かめていません（依頼がビルドと QEMU を禁じています）。

## 全体の結論

- 設定を扱う共通の形がありません。領域ごとに別の口があり、口の無い領域は変えられません。
- ユーザー空間のシステムのプロセスは、事実上 `init` 一つです。`init` はデスクトップの間は眠っています（`user/apps/init.c:160-165`）。
- 音、画面、入力、網、窓の管理、タスクバー、スタートメニューの持ち主は全部カーネルです。ABI の仕様書が「今はどれもカーネルの中」と書いています（`docs/nocturne-native-abi.md:1144`）。
- 利用者という物がありません。`C:\Users` の最初のフォルダーが「その利用者」です（`kernel/src/fs/store.c:395-420`）。
- 権限がありません。どのアプリも音量、画面のモード、電源、ほかのアプリの停止、画面の撮影を行えます。
- 「設定」という語は二つの別の物を指します。一つは `settings.ts` の値です。もう一つは起動時に渡す文字列 `NAME=value` で、環境変数と同じ物です（`user/include/nocturne.h:311-312`、`user/libc/sys.c:595-666`）。

## 7. 重い順の上位 20 件

1. **システムの層が無い。** 設定と方針の持ち主であるべきシステムのプロセスが、`init` のほかにありません。音、画面、入力、網、窓、タスクバー、メニューの持ち主は全部カーネルです（P1、`docs/nocturne-native-abi.md:1144`、`user/apps/init.c:155-182`）。
2. **設定の共通の形が無い。** 一つの値を足すと、カーネル、`js.c`、`js_ui.js`、型、窓の五か所を変えます。領域ごとに口が違い、適用と取消しの枠がありません（S1、S2、S3、S6、`user/apps/js.c:877-1054`、`common/display_abi.h:23-66`）。
3. **利用者が無い。** `C:\Users` の最初のフォルダーが利用者で、身元は文字列 `USERFOLDER` です。作成、切替え、ログインができません（U1、`kernel/src/fs/store.c:395-420`、`user/libc/sys.c:384-413`）。
4. **権限が無い。** どのアプリも電源を切り、ほかのアプリを止め、画面を読み、音量とモードを変えます（K1、K2、`kernel/src/sys/syscall.c:864-869,1205-1210`、`kernel/src/gui/wm.c:3379-3392`）。
5. **環境変数の改名がある。** `n_settings` は環境変数で、「設定」の語を奪っています。handle の番号まで文字列で渡します（F1、F2、`user/include/nocturne.h:311-312`、`user/libc/sys.c:595-666,809-822`）。
